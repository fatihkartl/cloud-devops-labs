# Linux Day 1 - Terminal

## Öğrendiğim Komutlar

- `pwd`
    
- `ls`
    
- `cd`
    
- `mkdir`
    
- `touch`
    
- `echo`
    
- `cp`
    
- `mv`
    
- `rm`
    
- `cat`
    

## Ne İşe Yarıyorlar?

- `pwd` → bulunduğum dizini gösterir.
    
- `ls` → bulunduğum dizindeki dosya ve klasörleri listeler.
    
- `cd` → dizin değiştirir.
    
- `mkdir` → yeni klasör oluşturur.
    
- `touch` → boş dosya oluşturur.
    
- `echo` → terminale veya dosyaya metin yazdırabilir.
    
- `cp` → dosya veya klasör kopyalar.
    
- `mv` → dosya taşır veya yeniden adlandırır.
    
- `rm` → dosya siler.
    
- `cat` → dosyanın içeriğini terminalde gösterir.
    

## Denediğim Örnekler

```
mkdir practice
touch notes.txt
echo "Linux terminal practice" > notes.txt
cat notes.txt
cp notes.txt notes-backup.txt
mv notes-backup.txt copied-notes.txt
rm copied-notes.txt
```
