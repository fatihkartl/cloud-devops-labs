# Linux Day 2 - Paths

## Öğrendiğim Kavramlar

- Absolute path
- Relative path
- `.`
- `..`
- `~`

## Kısa Notlar

- `/home/fatih/...` → absolute path
- `./` → bulunduğum dizin
- `../` → bir üst dizin
- `../../` → iki üst dizin
- `~` → home dizinim (`/home/fatih`)

## Örnek

`/home/fatih/path-lab/a/b/c` içinden `path-lab` klasörüne çıkmak için:

`../../../`

Dosya kopyalama örneği:

`cp orada.txt ../../../kopya.txt`
