# Linux System Health Checker

## Goal
Build a Bash script to automate basic Linux system health checks.

## Features
- Display system uptime and load averages
- Show RAM and swap usage
- Check filesystem disk usage
- Verify systemd service status
- Check whether important files exist

## Technologies
Linux, Bash, systemctl, coreutils

## Usage

    chmod +x system-health.sh
    ./system-health.sh

## What I Learned
Combined Bash functions, conditions, loops and Linux administration commands into a reusable system health check script.
